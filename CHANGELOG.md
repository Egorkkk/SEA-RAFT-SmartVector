# История версий

## v0.1.0 — первый релиз

- Нода SEA-RAFT SmartVector для Nuke с 28 каналами векторов и выводом через обычную `Write`.
- Кнопки **Export Write** и **Generate + Render** на основной вкладке, обновление ранее созданных нод.
- Установщик для Windows без WSL: изолированный Python, CUDA PyTorch, OpenEXR, SEA-RAFT и модель.
- Проверка установки, повторный запуск незавершённой генерации и хранение рабочих файлов вне очищаемого кэша Nuke.
- Проверка шаблона кадров и формата итогового EXR перед расчётом; контрольный тест направления оптического потока.
- Русскоязычная инструкция по установке, работе и диагностике.

Проверено на Nuke 17 / Windows / RTX 4060 Ti. Перед применением в кадре проверьте результат через `VectorDistort` на своём материале. Другие версии Nuke, рендер-ферма и автоматический контроль качества потока пока не проверены.
